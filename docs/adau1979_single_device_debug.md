# ADAU1979 单器件配置

当前工程固定使用一颗 ADAU1979，I²C 7 位地址为 `0x11`。

配置逻辑位于 `ip_repo/adau1979_capture_1.0/hdl/adau1979_i2c_init.v`，上电后保持原有低电平复位和等待时间，随后只向 `0x11` 写入一组寄存器并轮询该器件的 PLL。工程没有第二器件参数、相同地址判断、地址扫描或器件选择状态机。

I²C 写控制器和读控制器都接收 7 位地址。配置调用传入 `7'h11`，写事务内部发送 `0x22`，读事务内部发送 `0x23`。

单颗器件作为音频串行时钟主机输出 BCLK/LRCLK；PL 使用 `sdata[2]`/`sdata[3]` 接收两根 SDATAOUT。每个帧有 4 个有效 32 位采样，AXI 帧仍为 256 bit，低 128 bit 为有效数据，高 128 bit 为零填充。

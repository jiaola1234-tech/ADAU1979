# ADAU1979 地址脚（ADDR0/ADDR1）核实清单

> 目的：确认 U1/U2 的 ADDR 接法是否与 IP 参数 `U1_I2C_ADDR=0x11`、`U2_I2C_ADDR=0x31` 一致。
> 背景：项目文档 `docs/adau1979_vivado操作步骤.md` 第 40–56 行已写明——原理图中 U1、U2 的 ADDR0/ADDR1
> **每脚同时装有 10 kΩ 上拉和 10 kΩ 下拉**，静态电平被分压到约 1.65 V。该电平不是合法数字 0/1，
> 且两片器件会得到相同地址，属于**必须在焊接阶段完成的返工项**。

---

## 0. 数据手册依据（ADAU1979 Rev. B，Table 11 / Table 12）

I2C 首字节格式：`Bit7=ADDR1, Bit6=ADDR0, Bit5..Bit1=1_0_0_0_1, Bit0=R/W`

| ADDR1（pin 20 / CIN） | ADDR0（pin 19 / CLATCH） | 7 位地址 | 8 位写地址 |
|---|---|---|---|
| 0（低） | 0（低） | 0x11 | 0x22 |
| 0（低） | 1（高） | **0x31** | 0x62 |
| 1（高） | 0（低） | 0x51 | 0xA2 |
| 1（高） | 1（高） | 0x71 | 0xE2 |

另一个必须知道的事实：`ADDR0/CLATCH` 是复用脚，**CLATCH（即 ADDR0）被拉低 3 次会把芯片切到 SPI 模式**。
芯片一旦进入 SPI 模式，I2C 端口永不响应——现象正好是"连器件地址都不 ACK"。
1.65 V 的中间电平极易被噪声误触发，所以本项核实优先级最高。

## 1. 本项目目标接法（来自 `docs/adau1979_vivado操作步骤.md`）

| 器件 | 目标地址 | ADDR1 | ADDR0 | 需拆电阻 | 保留电阻 |
|---|---|---|---|---|---|
| U1 | 0x11 | 0（低） | 0（低） | R11.0、R12.0（两个上拉） | R13.0、R14.0（两下拉） |
| U2 | 0x31 | 0（低） | 1（高） | R11.1（ADDR1 上拉）、R14.1（ADDR0 下拉） | R13.1、R12.1 |

推得电阻与引脚的对应关系（与原理图局部图一致）：

- `R11.x` = ADDR1 上拉（到 IOVDD）
- `R13.x` = ADDR1 下拉（到 GND）
- `R12.x` = ADDR0 上拉（到 IOVDD）
- `R14.x` = ADDR0 下拉（到 GND）

## 2. 核实方法

### 方法 A：查图与查板（离线，最快）

1. 打开原理图（`tmp/pdfs/schematic_u1_crop.png`、`schematic_u2_crop.png`、`tmp_pdf/adau1979_schematic-1.png`）。
2. 目视确认 R11/R12/R13/R14 的四个焊盘是**已装**还是**空焊盘（DNP）**。
3. 未拆焊 → 直接判定为未返工，无需再测电压即可解释当前故障。

### 方法 B：断电电阻测量（判断电阻是否存在）

断电（或 ADAU 板单独断电）状态下，万用表电阻/二极管档，以 GND 为参考：

| 测量点 | 已拆（期望） | 未拆（异常） |
|---|---|---|
| U1 ADDR1 ↔ GND | ≈10 kΩ（R13.0 在，R11.0 已拆） | ≈5 kΩ（10k∥10k） |
| U1 ADDR1 ↔ IOVDD/3.3V | 开路（R11.0 已拆） | ≈10 kΩ |
| U1 ADDR0 ↔ GND | ≈10 kΩ | ≈5 kΩ |
| U1 ADDR0 ↔ IOVDD | 开路 | ≈10 kΩ |
| U2 ADDR1 ↔ GND | ≈10 kΩ | ≈5 kΩ |
| U2 ADDR1 ↔ IOVDD | 开路 | ≈10 kΩ |
| U2 ADDR0 ↔ IOVDD | ≈10 kΩ（R12.1 在，R14.1 已拆） | ≈5 kΩ |
| U2 ADDR0 ↔ GND | 开路（R14.1 已拆） | ≈10 kΩ |

U1 与 U2 的比较判据：**两片的 ADDR0 对轨电阻必须不同**（U1 只到 GND，U2 只到 IOVDD）。

### 方法 C：上电电压测量（决定性判据）

给 ADAU 板上电，ADDR 脚应为稳定的轨到轨电平：

| 器件/引脚 | 期望电压 | 判定 |
|---|---|---|
| U1 ADDR1（pin 20） | ≈0 V | 0 V = 0x11 正确 |
| U1 ADDR0（pin 19） | ≈0 V | 0 V = 0x11 正确 |
| U2 ADDR1（pin 20） | ≈0 V | 0 V 正确 |
| U2 ADDR0（pin 19） | ≈3.3 V | 3.3 V = 0x31 正确 |
| 任意一脚实测 ≈1.6–1.7 V | — | **返工未完成**，必判失败 |

测量注意事项：

1. ADAU1979 为 40 脚 LFCSP（6×6 mm，引脚间距 0.5 mm），**不要直接戳芯片引脚**；
   在 R11~R14 的焊盘、或该网络的过孔/测试点上测量。
2. 先把 ADDR 脚与电阻之间确认是同一网络（用蜂鸣档从电阻焊盘通到芯片引脚焊盘）。
3. 用 IOVDD（3.3 V）作为高电平参考，不要用 AVDD 或 5 V。

### 方法 D：运行时交叉验证（不依赖返工，用于佐证）

1. **外部 I2C 主机扫描**：用 CH341A / CP2112 USB 转 I2C 模块或 Arduino/RP2040，扫描
   0x11 / 0x31 / 0x51 / 0x71 四个地址：
   - 任一地址有 ACK → 地址脚电平有效，可据此修正 IP 参数；
   - 四个地址全无 ACK → 电平非法（1.65 V）、未供电、被拉死或已进入 SPI 模式。
2. **用现有固件判读 `ACK_BITS`**（AXI 偏移 0x28，bit0=器件地址 ACK、bit1=寄存器 ACK、bit2=数据 ACK）：
   - 返工前后对比：返工后写 U1（0x11）应出现 `ACK_BITS=7`；
   - 当前实测 `ACK_BITS=0`（连器件地址都 NACK）→ 与"地址脚停在 1.65 V / 地址不匹配"一致。
3. **改 IP 参数重建**（仅作诊断）：把 `U1_I2C_ADDR` 依次改为 0x31/0x51/0x71 重新生成 bitstream。
   注意：若引脚仍停在 1.65 V，此法结果不可靠，必须先完成返工。

## 2.5 实物板上的定位（结合 2026-09-14 提供的实物照片与 PCB 版图截图）

版图分析结论：**每片 ADAU1979 旁边都有一组 6 个 0402 电阻**，位置在芯片的 SCL/SDA/ADDR 引脚那一侧
（版图中位于芯片右上方),结构完全对称：

```text
             (接 IOVDD 的公共上拉排)
   ┌──────┬──────┬──────┬──────┐
   │ R11  │ R12  │  R9  │ R10  │   10k   10k   2k    2k
   ├──────┼──────┤      │      │
   │ R13  │ R14  │      │      │   10k   10k  (接到 GND)
   └──────┴──────┘
     ADDR1  ADDR0     SCL   SDA
```

- `R11` = ADDR1 上拉（10 kΩ → IOVDD），`R13`（R11 正下方）= ADDR1 下拉（10 kΩ → GND）
- `R12` = ADDR0 上拉（10 kΩ → IOVDD），`R14`（R12 正下方）= ADDR0 下拉（10 kΩ → GND）
- `R9`/`R10` = SCL/SDA 的 2 kΩ 上拉，**与地址无关，不要拆**（是否必须贴装见第 2.6 节）
- U1 组标号为 `R11.0 / R12.0 / R13.0 / R14.0`；U2 组为 `R11.1 / R12.1 / R13.1 / R14.1`

版图截图的注意事项：该视图中元件丝印文字是镜像显示的，**不要按截图的左右顺序去数件**，
请以万用表实测（方法 B/C）或 EDA 的"查找/高亮"功能定位。

该板其它被高亮圈出的元件与地址无关，**不要拆**：

| 元件 | 作用 |
|---|---|
| R9 / R10（2 kΩ） | I²C SCL/SDA 上拉（**不可拆**；U2 那对可空贴，见 2.6） |
| R16（47 kΩ） | PD/RST 上拉 |
| R17（1 kΩ）+ C20（390 pF）+ C21（5600 pF） | PLL_FILT 环路滤波 |
| R20（3 kΩ） | VREF 相关 |
| R18 / R19（33 Ω） | SDATAOUT 串联电阻 |

从实物照片看，地址电阻 `R11~R14` 的两组位置似乎都处于已贴装状态，据此初步判断返工尚未完成。
照片分辨率约 6 px/mm，**无法可靠判读 0402 焊盘是否空焊**，该判断只能作为参考，
最终以断电电阻测量 / 上电电压测量为准。

> 2026-09-14 用户现场反馈：U2 组的 `R9.1`、`R10.1`（2 kΩ 上拉）未贴装。见第 2.6 节——
> 该情况本身没有问题，但必须确认「全总线至少还有一套 2 kΩ 上拉」贴装到位。

## 2.6 `R9.1` / `R10.1`（U2 组 I²C 上拉）是否可以空贴

**结论：可以空贴，不影响功能。** 前提是 U1 组那对 `R9.0` / `R10.0` 在位。

依据：

1. `R9.x` / `R10.x` 是 **SCL/SDA 到 IOVDD 的 2 kΩ 上拉**，与地址无关。
   BOM 中 2 kΩ 共 4 只：`R9.0, R9.1, R10.0, R10.1`（0603）；原理图中该网络附近并列出现
   `SCL`、`SDA`、`R9.x`、`R10.x`、`IOVDD`，100 Ω 的 `R1~R8` 全部挂在 `AIN1~AIN8` 模拟输入上，
   **I²C 通路上没有任何串联电阻**。
2. IP 只引出一对 `adau_scl` / `adau_sda`（`adau1979_capture_v1_0.v` L22–23），
   约束里也只有一对引脚（SCL=W19 / SDA=W18），**U1 与 U2 共用同一条 I²C 总线**。
   因此两组上拉是**并联**关系：

| 贴装情况 | 总线等效上拉 | 3.3 V 下灌电流 | 评价 |
|---|---|---|---|
| 只装 U1 组 `R9.0`/`R10.0` | 2 kΩ | 1.65 mA | **推荐**，余量充足 |
| 两组都装 | 1 kΩ | 3.3 mA | 可用但偏紧：已达 I²C VOL 测试条件（3 mA）上限，总线电容稍大时 VOL 会超标 |
| 两组都不装 | 开路 | — | **故障**：SDA/SCL 悬空，主机读回恒 0，正是当前现象 |

3. 因此空贴 U2 组那对，**比两组都装更稳妥**（少一对并联电阻，等效上拉回到 2 kΩ）。

**必须补的一个验证（30 秒）**：确认“还有一套上拉在位”，方法是断电用电阻档测
`SCL ↔ IOVDD`、`SDA ↔ IOVDD`：

- ≈ 2 kΩ → 只有一套在位，正确；
- ≈ 1 kΩ → 两套都在位（能用，但建议拆掉一套）；
- 开路 / ∞ → **一套都没有**，这就是当前 `sda_i` 恒低的直接原因，必须补焊 U1 组那对。

另外提醒：若万用表确认 `R9.0`/`R10.0` 已在位，而上电后 SDA 空闲仍为 0 V，
则问题不在电阻本身，而在 **IOVDD 是否真的加到上拉电阻的上端**（模块供电 / 共地 / 飞线）。
测量点选上拉电阻靠 IOVDD 的那一端，而不是芯片引脚。

## 4. 返工后的复测顺序

1. 断电 → 方法 B 确认电阻状态。
2. 上电 → 方法 C 确认四脚电平。
3. 复位 FPGA → 运行 Vitis 程序，发送 `r` 重新初始化。
4. 判读串口：`ACK_BITS` 应为 7、`ADAU1979 init done`，随后 `pll_ack_error` 应为 0、
   两片 `PLL_CONTROL(0x01)` 的 bit7 `PLL_LOCK` 应为 1。
5. 若仍 `ACK_BITS=0`：按以下顺序排查——
   ① 断电测 `SCL/SDA ↔ IOVDD` 电阻，确认全总线**至少有一套 2 kΩ 上拉在位**（第 2.6 节）；
   ② 上电测该上拉电阻上端对 GND 是否 3.3 V（模块供电 / 共地 / 飞线）；
   ③ 再查 PD/RST 时序与总线是否被从机拉死。
